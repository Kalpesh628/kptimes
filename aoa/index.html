The pattern — one fixed anchor, the rest rotates

AOA is looser than DSGT: topics rotate across slots instead of sitting in one fixed slot. The one anchor: Merge Sort is Q2b in both papers (10 marks each). Q1 is always six 3-mark shorts, any five. Q2 is sorting + spanning tree both times. Q6 is three 5-mark shorts both times. Everything else — Kruskal vs Prim, Floyd-Warshall vs Dijkstra, LCS, knapsack, multistage, coloring — moves between Q3, Q4 and Q5. Learn the topic, not the slot.
