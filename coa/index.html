The pattern — Q5 never moves, the rest rotates

The safest 15 marks in COA: Q5 is identical in topic both papers — 8086 architecture (8) + Booth's algorithm (7). Q1 always holds number conversion and associative memory, with two rotating slots. The other big topics — non-restoring division, cache mapping, pipeline hazards, I/O methods, control unit, Flynn's — all appear both times but move slots between Q2, Q3, Q4 and Q6. Learn the topic, not the slot.

Rank 1 — 16 marks each, asked 2/2 papers

Explain with a suitable diagram the architecture of the 8086 microprocessor — same question, same slot, same marks, both papers. Draw it once, neatly, and reuse it.

Dec Q3a: 64MB main memory, 32KB cache, 8-byte lines — memory-address format for Direct and Associative mapping. May Q4a: compare Direct, Associative, Set Associative cache mapping techniques.

Dec Q2a: flowchart + implement for (13/3). May Q3a: flowchart + solve (15)₁₀ / (2)₁₀. Same algorithm, different numbers — practice it with any two numbers until the flowchart is automatic.

Rank 2 — control unit and the 14-mark topics

Explain micro-programmed control unit with a suitable diagram.

Compare hardwired and softwired (microprogrammed) control unit design techniques.

Differentiate horizontal and vertical microinstruction. (Control-unit family total: 20.)

Dec: multiply (12)₁₀ and (−5)₁₀. May: multiply (−8)₁₀ and (−3)₁₀. Same slot as 8086 architecture — Q5 is a ready-made 15 marks.

Dec Q4b: various pipeline hazards + methods to resolve them. May Q2b: different pipeline hazards. (May Q1b also asks the instruction pipeline concept, 5 — counted separately below.)

Dec Q3b: programmed I/O, interrupt-driven I/O, DMA — explain and compare. May Q3b: programmed IO and interrupt-driven data transfer methods.

Dec Q6b (5), May Q6a (8) — explain Flynn's classification. In Q6 both times, but worth more in May.

Dec Q2b (7): memory hierarchy with diagrams and characteristics of memory. May Q1c (5): characteristics of memory.

Rank 3 — Q1 regulars and single-paper topics

Dec: (345.35)₁₀ and (818.55)₁₀ to Binary, Octal, Hexadecimal. May: (74.25)₁₀ and (47.50)₁₀ to Hexadecimal + addition on the converted numbers. No conversion calculator allowed — practice by hand.

Dec Q1c: associative memory with usages. May Q1d: associative memory.

Explain ISA, PCI and USB buses.

Explain bus arbitration with examples.

Q1 — Attempt any THREE (5M each). A: Convert (345.35)₁₀ and (818.55)₁₀ to Binary, Octal and Hexadecimal. B: Addressing modes of 8086 with example. C: Associative memory with usages. D: ISA, PCI and USB buses.

Q2 A) (8) Flowchart for non restoring division algorithm, implement for (13/3). B) (7) Memory hierarchy with diagrams and characteristics of memory.

Q3 A) (8) 64MB main memory, 32KB cache, 8-byte lines — memory-address format for Direct and Associative mapping. B) (7) Programmed I/O, interrupt-driven I/O, DMA — explain and compare.

Q4 A) (8) Micro-programmed control unit with diagram. B) (7) Various pipeline hazards + methods to resolve them, with drawings and explanation.

Q5 A) (8) Architecture of 8086 microprocessor with diagram. B) (7) Multiply (12)₁₀ and (−5)₁₀ using Booth's algorithm.

Q6 A) (5) Bus arbitration with examples. B) (5) Flynn's classification. C) (5) Horizontal vs vertical microinstruction.
