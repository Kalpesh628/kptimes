The pattern, first — because DSGT barely moves

DSGT is the most predictable paper of the semester. Every single slot asks the same topic in both papers. Q1a is equivalence both times, Q1b is logical equivalence both times, Q1c is pigeonhole both times — all the way down to Q6b, Euler/Hamiltonian both times. If you learn the slot list below, you have learned the paper. The only thing that changes is the story wrapped around the question.

Rank 1 — 16 marks each, asked 2/2 papers

Dec: event-app sections (E 140, C 110, R 120, overlaps 65/70/55, total 200) — all three sections, only one section. May: drug trial on 1000 people (symptoms 122/88/112, pairs 27/29/32, all three 10) — at least one symptom, exactly one symptom, Venn diagram.

Dec: prerequisite network M1–M5, relation {(1,2),(2,3),(3,4),(4,5),(1,1),(3,3),(5,5)} — Warshall's algorithm, modules each Mi unlocks, root and terminal modules. May: airline network V = {a,b,c,d}, R = {(a,b),(b,d),(d,c),(d,a)} — direct routes, routes with layovers, circular routes, final connectivity relation.

Dec: token T(a) = (a × k) mod 7, a ∈ {1…6} — multiplication table, inverses of 2, 3, 5 mod 7, is ({1…6}, ×₇) a group? May: G = {1,2,3,4,5,6} under multiplication mod 7 — table, inverses of 2, 3, 5, 6, is G cyclic, find a generator.

Dec: surveillance networks G₁ (A,B,C,D) vs G₂ (P,Q,R,S) — isomorphic? give the mapping. May: network layouts G₁ (A,B,C,X,Y,Z) vs G₂ (1–6) with full edge lists — define isomorphism, decide, give the one-to-one correspondence, justify by degree sequence and adjacency.

Dec: (Z₆, ⊕, ⊗) with a ⊕ b = (a+b) mod 6, a ⊗ b = (a×b) mod 6 — abelian group check, closure/associativity, distributivity, is it a ring? May: Z₄ = {0,1,2,3} with addition and multiplication mod 4 — both tables, ring properties, additive identity/inverse, associativity, distributive laws.

Rank 2 — 14 marks each, asked 2/2 papers

Dec: M(x) = x + 5, W(x) = 0.4x — compute W∘M, M∘W, M∘M, W∘W, and say which are academically meaningful. May: shirt Rs. 1000, 15% discount then 8% tax — functions for discount and tax, composite function for final cost, final amount.

Dec: S = {1 TB, 2 TB, 4 TB, 8 TB, 16 TB} under divisibility — Hasse diagram, all (a,b) with a | b, is S a lattice? May: A = {1,2,3,6,12,24,36,72}, (x,y) ∈ R if x | y — all ordered pairs, Hasse diagram, lattice? justify with meet and join.

Dec: prove Sₙ = 4n − 1 is always odd for all natural n. May: prove Σr=1n r(r + 3) = (1/3)n(n + 1)(n + 5) for all n ≥ 1 — base case, inductive step, conclusion.

Dec: Fₙ = 4Fₙ₋₁ − 4Fₙ₋₂, F₀ = 10, F₁ = 30 — solve it, describe growth (linear/exponential), is it realistic long term? May: Fₙ = 3Fₙ₋₁ + 10Fₙ₋₂ + 7·5ⁿ, F₀ = 4, F₁ = −3 — solve, general expression, effect of the 7·5ⁿ forcing term.

Dec: graph V = {A,B,C,D,E,F}, E = {AB, AC, BC, BD, CE, DE, DF, EF} — Euler path, Euler circuit, Hamiltonian path, Hamiltonian circuit: exist? construct if so. May: road network on six locations A–F (graph figure not legible in scan) — same four determinations, justified by vertex degrees and traversal conditions.

Rank 3 — 10 marks each, asked 2/2 papers (Q1 shorts)

Dec: feedback responses grouped by satisfaction band (1–2 Low, 3 Medium, 4–5 High) — is "similarity" an equivalence relation? May: polygons grouped by number of sides, R = {(P₁,P₂): same number of sides} — equivalence classes for triangles, quadrilaterals, pentagons.

Dec: prove (P ∨ Q) → R ≡ (P → R) ∧ (Q → R) using logical equivalence laws. May: prove ((p → q) → r) ≡ (p ∧ ¬q) ∨ r using a series of logical equivalences.

Dec: 240 contestants, 12 judging terminals — minimum sharing a terminal. May: 10 pairs of socks in a drawer — minimum socks to guarantee a matching pair.

Rank 4 — Dec only, 5 marks each

Access A = (P ∧ Q) ∨ (P ∧ R) with P: lab clearance, Q: signed NDA, R: safety briefing — truth table, wrongly-granted combinations, consequences for security and audit.

Tracks by score: Coding ≥ 80 → Software, Networks ≥ 75 → Network Security, Math ≥ 85 → Data Science (priority Data Science > Software > Network Security); students S1 (85,60,70), S2 (65,80,90), S3 (82,78,88), S4 (78,76,60) — map each student, check function / one-one / onto / many-one.

Exact papers — DSGT

Both papers in original order and numbering, marks on the right, tables as printed. The full verbatim transcript lives in the study notes; the questions below are reproduced as printed, including the scan gaps flagged under the slot map.

Dec 2025 — QP 99814 · 3 hours · 60 marks · 19/12/2025

Q1 — Attempt any three out of six sub questions (05M each). a) Student-feedback system, "similar" = same satisfaction band (1–2 Low, 3 Medium, 4–5 High): is similarity an equivalence relation? meaning of each property? effect of violating a property on AI feedback analytics? b) Bus attendance: (P ∨ Q) → R ≡ (P → R) ∧ (Q → R) — prove by logical equivalence laws; why it ensures no boarding method is ignored. c) Programming contest, 240 participants, 12 terminals — Pigeonhole minimum sharing a terminal; use in scheduling and load balancing. d) Cybersecurity lab access A = (P ∧ Q) ∨ (P ∧ R) — truth table, wrongly-granted combinations, security/audit consequences. e) Specialization tracks (Coding ≥ 80 → Software; Networks ≥ 75 → Network Security; Math ≥ 85 → Data Science; priority Data Science > Software > Network Security), students S1 (85,60,70), S2 (65,80,90), S3 (82,78,88), S4 (78,76,60) — map each student; function / one-one / onto / many-one?; impact on batch size, mentors, fairness.

Q2 a) (08M) Campus event app sections E/C/R with survey table E 140, C 110, R 120, E∩C 65, E∩R 70, C∩R 55, Total 200 — inclusion–exclusion: all three sections? only one section? use for notifications and UI. b) (07M) M(x) = x + 5, W(x) = 0.4x — compute W∘M, M∘W, M∘M, W∘W; which are academically meaningful, which distort scores?

Q3 a) (08M) Prerequisite network M1–M5, R = {(1,2),(2,3),(3,4),(4,5),(1,1),(3,3),(5,5)} — Warshall's transitive closure, modules each Mi unlocks, root and terminal modules. b) (07M) Storage plans S = {1, 2, 4, 8, 16 TB} under divisibility — Hasse diagram, all (a,b) with a | b, is S a lattice?; upgrade/downgrade recommendations.

Q4 a) (08M) QR token T(a) = (a × k) mod 7, a ∈ {1…6} — multiplication table (×₇), inverses of 2, 3, 5 mod 7, is ({1…6}, ×₇) a group? reversibility, forgery prevention, validation. b) (07M) Daily saving Sₙ = 4n − 1 — prove Sₙ is always odd by mathematical induction; meaning for weekly budgets and long-term savings.

Q5 a) (08M) Surveillance graphs G₁ (A: B,C; B: A,D; C: A,D; D: B,C) vs G₂ (P: Q,R; Q: P,S; R: P,S; S: Q,R) — isomorphic? mapping? reuse of layouts. b) (07M) Club followers Fₙ = 4Fₙ₋₁ − 4Fₙ₋₂, F₀ = 10, F₁ = 30 — solve, growth pattern, realistic long term?

Q6 a) (08M) Lab-batch rotation: a ⊕ b = (a+b) mod 6, a ⊗ b = (a×b) mod 6 — is (Z₆, ⊕) abelian? closure/associativity of ⊗? distributivity? is (Z₆, ⊕, ⊗) a ring? b) (07M) Conference venue graph V = {A,B,C,D,E,F}, E = {AB, AC, BC, BD, CE, DE, DF, EF} — Euler path, Euler circuit, Hamiltonian path, Hamiltonian circuit: exist? construct? visitor flow and inspection rounds.

Q1 (05M each, as printed a–c). a) Polygons grouped by number of sides, R = {(P₁,P₂): same number of sides} — equivalence relation? properties? classes for triangles, quadrilaterals, pentagons? b) Prove ((p → q) → r) ≡ (p ∧ ¬q) ∨ r by logical equivalences; how equivalence simplifies decision rules. c) 10 pairs of socks in a drawer — Pigeonhole minimum to guarantee a matching pair, with reasoning.

Venn diagram. b) (07M) Shirt Rs. 1000, 15% discount then 8% tax — functions for discount and tax, composite function for final cost, final amount, how composites automate billing.

Q3 a) (08M) Airline network V = {a,b,c,d}, R = {(a,b),(b,d),(d,c),(d,a)} — reachability / transitive closure, direct routes, layover routes, circular routes, final connectivity relation. b) (07M) Permission levels A = {1,2,3,6,12,24,36,72}, (x,y) ∈ R if x | y — all ordered pairs, Hasse diagram, lattice? meet and join examples.

Q4 a) (08M) G = {1,2,3,4,5,6} under multiplication mod 7 — multiplication table, inverses of 2, 3, 5, 6, is G cyclic? find a generator. b) (07M) Prove Σr=1n r(r + 3) = (1/3)n(n + 1)(n + 5) by induction — base case, inductive step, conclusion.

Q5 a) (08M) Network layouts V(G₁) = {A,B,C,X,Y,Z}, E(G₁) = {(A,X),(A,Y),(B,X),(B,Y),(C,Y)}; V(G₂) = {1,2,3,4,5,6}, E(G₂) = {(1,4),(1,5),(2,4),(2,5),(3,5)} — define isomorphism, isomorphic? one-to-one correspondence? degree sequence and adjacency. b) (07M) Portfolio Fₙ = 3Fₙ₋₁ + 10Fₙ₋₂ + 7·5ⁿ, F₀ = 4, F₁ = −3 — solve, general expression, effect of 7·5ⁿ, use in forecasting.

Q6 a) (08M) Z₄ = {0,1,2,3} with addition and multiplication mod 4 — both tables, ring properties, additive identity/inverse, associativity, distributive laws, is Z₄ a ring? b) (07M) Road network on six locations A–F [graph figure not legible in scan] — Euler path? Euler circuit? Hamiltonian path? Hamiltonian circuit? justify by vertex degrees and traversal conditions.
