Campus Canteen
Pre-Order & Pickup.

No more canteen queues. Students pre-order food and reserve a pickup slot from their phone; the canteen sees every order move through a live status pipeline.

What it does

Two roles, one smooth flow — built for a real college canteen rush.

🎓 Student

Register & log in · browse the menu with search and veg filters · session cart · choose a pickup slot (capacity-checked, race-safe) · pay at canteen · track the order live · order history · rate the food.

🧑‍🍳 Canteen Admin

Dashboard with today's orders, revenue and pending counts · full menu CRUD · accept / reject orders with reasons · advance order status · manage pickup slots and per-slot capacity · sales stats · read all feedback.

Order lifecycle

Every order moves through this pipeline — students watch it happen in real time.

PLACED

Student checks out with a pickup slot. Payment mode: pay at canteen.

ACCEPTED

Canteen confirms the order — or rejects it with a reason.

PREPARING

Kitchen starts cooking. The student sees the status change live.

READY

Food is packed and waiting at the counter for the slot.

PICKED_UP

Student collects, pays, and can leave a rating.

How it works

Classic, viva-explainable architecture. No frameworks, no magic.

JSP view

Bootstrap pages render the UI and submit forms — menu, cart, checkout, tracking.

Servlet controller

Twelve servlets validate input, manage the session, and route — e.g. OrderServlet recomputes totals server-side, never trusting the browser.

DAO model

JDBC data-access objects run every query as a PreparedStatement. Slot booking locks the row (SELECT … FOR UPDATE) so two students can't grab the last slot.

MySQL database

Six tables: users, menu items, pickup slots, orders, order items, feedback. Passwords stored as salted SHA-256 hashes.

Run it yourself

Three commands and a Tomcat — the README inside the ZIP walks through every step.

# 1. Create the database
mysql -u root -p < schema.sql

# 2. Build the WAR
mvn package

# 3. Deploy — copy target/campus-canteen.war
#    into Tomcat's webapps/ and open
http://localhost:8080/campus-canteen

# Admin login (change after first sign-in)
admin@canteen.local / admin123
